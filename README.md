# Lo de Adri

App del puesto de diarios y revistas: stock, reservas, ventas, catálogo para clientes y ráfagas para redes.

- App del puesto: https://rodrigobarretto.github.io/lo-de-adri/
- Catálogo para clientes: https://rodrigobarretto.github.io/lo-de-adri/?catalogo

`instalar.sql` es la instalación de la base en Supabase (ya está hecha en el proyecto "Lo de Adri").
Cada vez que se cambie la app, subir el número de `VERSION` en `sw.js`.
